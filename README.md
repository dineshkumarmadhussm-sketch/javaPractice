# Java Fundamentals & Practice
A collection of Java programs and mini-projects developed to master core programming concepts, from basic syntax to Object-Oriented Programming (OOP).

🚀 Concepts Covered
Core Java: Variables, Data Types, and Operators.

Control Flow: If-else statements, Switch cases, and Loops (For, While, Do-While).

OOPs Principles:

Encapsulation: Using private fields and getters/setters.

Inheritance: Extending classes for code reusability.

Polymorphism: Overloading and Overriding methods.

Abstraction: Working with Abstract classes and Interfaces.

Data Structures: Arrays, ArrayLists, and HashMaps.

Exception Handling: Using Try-Catch blocks to manage errors.

🛠 Projects Included
Student Management System: A console-based app to manage student records using ArrayLists.

Basic Calculator: Performs arithmetic operations using switch-case logic.

Bank Account Simulator: Demonstrates Encapsulation and Inheritance by handling deposits and withdrawals.
